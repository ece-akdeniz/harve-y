# Lab API contract (v1)

All JSON routes except login require either the session cookie or `Authorization: Bearer <upload token>`.
Only bearer authentication may PUT snapshots. Login cookie grants reads only. Static assets contain no data.
Errors: `{ "error": "safe message" }`, HTTP 400/401/404/409/413 as appropriate.

- `POST /api/login` JSON `{password}` -> 200 `{ok:true}` plus session cookie.
- `POST /api/logout` -> 200 and expired cookie.
- `GET /api/runs` -> `{runs:[Summary], quota:null|{used,left,limit,checked_at}, team:"y/agent"}`.
- `GET /api/runs/<run_id>` -> Run.
- `PUT /api/runs/<run_id>` -> `{ok:true, accepted:true|false}`. ID must match body.
- `GET /api/compare?baseline=<id>&candidate=<id>` -> Comparison.

Run:
```json
{
  "schema_version":1,"run_id":"uuid-or-import-id","revision":1,
  "name":"Payment experiment","author":"Samet","hypothesis":"Earlier payment improves total cost",
  "agent":"package","config":{"anchor":0.12},"source":"tracked","environment":"sandbox",
  "arena_url":"https://arena.tacto.ai","baseline_id":null,
  "started_at":"2026-10-10T12:00:00+00:00","updated_at":"2026-10-10T12:00:00+00:00",
  "status":"running","cases":["case:D01"],"repetitions":1,
  "provenance":{"commit":"abc","dirty":false,"patch_sha256":null,"lock_sha256":"...","data_sha256":null},
  "quota":null,
  "attempts":[{
    "attempt_id":"case:D01:1","case_id":"case:D01","repeat":1,"status":"pending",
    "session_id":null,"replay_url":null,"score":null,"rounds":null,"elapsed_s":null,
    "timeouts":null,"error":null,"result":{},"threads":{}
  }]
}
```
Run status: running/completed/failed/interrupted. Attempt status: pending/running/completed/failed.
Source: tracked/imported. Environment: simulator/sandbox/practice. Unknown provenance stays null
or `{}` for imports. A no-deal may have a real score; an infrastructure failure may have none.

Summary: run_id,name,author,hypothesis,agent,source,environment,arena_url,status,started_at,updated_at,
baseline_id,provenance,revision, and
`metrics:{planned,completed,failed,pending,scored,recovered,mean_score,observed_mean,min_score,deals,elapsed_s,timeouts}`.
`mean_score` is null unless every planned attempt has a completed valid outcome. `observed_mean`
averages only known scores and must be labeled partial. Scores are 0..1; UI displays x100.
`recovered` counts separately recovered official outcomes in `attempt.result.reconciled_result`,
with an explanatory `reconciliation_note`. Recovery leaves original tracked status, errors and
primary score metrics unchanged. Additive recovery does not consume a laptop writer revision;
clients should refresh details when the summary changes, including its recovered count.

Comparison:
```json
{
 "baseline":{},"candidate":{},"warnings":[],"mean_delta":null,
 "cases":[{"case_id":"case:D01","baseline_mean":0.5,"candidate_mean":0.6,"delta":0.1,
   "baseline_scored":1,"candidate_scored":1,"baseline_planned":1,"candidate_planned":1,
   "baseline_failed":0,"candidate_failed":0}],
 "comparable":true
}
```
`baseline`/`candidate` are Summaries. Cases are the union with missing sides visible. Deltas are
null for incomplete cells. Overall delta is case-weighted on common complete cases only and null
if none or environments differ. Warnings state unmatched cases, unequal repeats, incomplete cells,
unknown/different data, dirty code and imported provenance limitations. No causal/statistical claims.

Module entry point: `python -m negotiator.lab`. Existing CLI dispatches `negotiator lab ...`.
Environment: `LAB_URL`, `LAB_UPLOAD_TOKEN`, `LAB_PASSWORD`, `LAB_AUTHOR`. Host secret file:
`.lab-secrets.env`; `lab init` creates it mode 0600 without printing values. Host DB default:
`experiments/dashboard.sqlite3`. Local snapshots: `experiments/runs/<run_id>/run.json`.
UI login uses password, uploads use token. No tokens in query parameters/localStorage.
